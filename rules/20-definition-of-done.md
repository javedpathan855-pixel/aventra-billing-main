# 20 — Definition of Done

A task is complete only when:

- Correct feature and layer ownership.
- All four feature layers remain architecturally intact.
- Directory taxonomy is respected.
- No forbidden cross-layer imports.
- Domain remains framework-independent.
- No arbitrary dumping-ground directory.
- UI is accessible.
- Colors use global tokens.
- `cn()` is used for composed Tailwind classes.
- Animation is in the correct global/feature location.
- No legacy/unnecessary dependency was introduced.
- No mock leakage remains.
- Authorization and input validation are correct.
- Relevant Vitest tests pass.
- TypeScript passes.
- ESLint passes.
- Build passes when applicable.
- Git diff has been reviewed.
- No secrets/debug/dead code remain.
- Documentation/rules are updated when architecture changes.
